# NOVA SHOP — UI/UX Pro Max Design Notes

This storefront is a Laravel Blade + Vite implementation using design guidance from the public UI/UX Pro Max skill.

Design direction:
- RTL-first Persian commerce experience
- Minimal ecommerce visual language with teal brand color and amber emphasis
- Clear hierarchy, generous spacing, compact cards, visible focus/click affordances
- Responsive targets for mobile, tablet and desktop
- Reduced-motion handling
- No emoji icons; interface icons are inline SVG/text-safe symbols
- Product search filters visible cards
- Cart quantity and running total update client-side

Reference skill: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
Skill version reviewed: 2.13.0
